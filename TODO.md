# UA Parser 5.0 — план робіт

## Реалізовано в alpha.1
- [x] Адмін-сторінка WordPress.
- [x] Аналіз однієї публічної сторінки.
- [x] Евристичне витягування заголовка, опису, ціни та URL зображень.
- [x] Тимчасове збереження набору для поточного адміністратора.
- [x] CSV-експорт із роздільником крапка з комою.
- [x] Публікація як WordPress post/page.
- [x] Базова публікація простого WooCommerce product.
- [x] Завантаження першого зображення як мініатюри.
- [x] Перевірка повторів за URL джерела.
- [x] Адаптивні стилі.

- [ ] Візуальний вибір елементів у безпечному ізольованому preview.
- [ ] Автоматичне знаходження повторюваних карток товарів/записів.
- [ ] Обхід категорій, пагінації та sitemap.
- [ ] Пакетна черга з прогресом, повторами та журналом помилок.
- [ ] Збережені шаблони селекторів і профілі збору.
- [ ] Редагування полів і вибір окремих записів перед публікацією.
- [ ] Повна галерея товару, SKU, бренд, категорії, мітки, атрибути та варіації.
- [ ] Профілі CSV для WooCommerce, Prom, Rozetka, OpenCart, Joomla/VirtueMart/JoomShopping.
- [ ] Профілі звичайних записів WordPress та довільних post types.
- [ ] Налаштовуваний роздільник CSV та вибір полів експорту.
- [ ] Англійська локалізація.
- [ ] Freemius PRO після отримання підтверджених ідентифікаторів/ключів.
- [ ] GitHub updater.
- [ ] Автоматичні тести PHP 7.4+ і перевірка сумісності з WordPress/WooCommerce.
- [ ] Додатковий аудит SSRF, DNS rebinding, редиректів і медіа-завантажень.

## Відомі обмеження
- Публікація поки бере весь зібраний набір; серверна фільтрація вибраних позицій ще не зроблена.
- Для товарів створюється простий WooCommerce product; SKU, категорії, атрибути, варіації та галерея не переносяться.
- Збір полів евристичний, результати потрібно перевіряти.
- Зовнішній сайт може блокувати запити або повертати неповний HTML.
- Ця гілка не проходила тестування на реальному WordPress-сайті.
