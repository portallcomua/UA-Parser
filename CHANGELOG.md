# UA Parser — журнал змін

## 5.0.0-beta.8
- Додано редагування зібраних матеріалів перед публікацією: назва, опис, ціна, URL фото, атрибути та варіації.
- Додано виявлення sitemap.xml та Sitemap-директив у robots.txt для початкового наповнення черги.
- Посилено перевірку даних, що надходять з редактора результатів.
- Додано вибір товарів/матеріалів для публікації та захист від публікації всього набору при порожньому виборі.


## 5.0.0-alpha.1
- Початкова основа нового адмінінтерфейсу.
- Аналіз і збір однієї публічної сторінки.
- Евристичне витягування заголовка, опису, ціни та зображень.
- Тимчасове зберігання результатів для поточного адміністратора.
- CSV-експорт.
- Базова публікація записів, сторінок і простих товарів WooCommerce.
- Пропуск дублікатів за URL джерела.
- Адаптивний український інтерфейс.

Це alpha-збірка для тестування, не фінальний реліз.
