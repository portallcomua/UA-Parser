Універсальний збирач публічних вебсторінок для підготовки даних до WordPress та WooCommerce.

== Поточний стан beta.8 ==
* Базове отримання HTML публічних HTTP/HTTPS сторінок.
* Універсальне витягування даних з HTML незалежно від CMS джерела.
* Витягування до 50 зображень, включно з lazy-load, Open Graph, JSON-LD та галерейними посиланнями.
* Збір множинних значень атрибутів із мікророзмітки, структурованих даних, select та swatch-елементів.
* Підтримка ProductGroup/hasVariant у структурованих даних та створення WooCommerce variable product із знайдених варіантів.
* Завантаження зібраних фото до медіатеки та формування головного фото й галереї WooCommerce.
* Попередній перегляд сторінки в ізольованому iframe та основа візуального вибору CSS-селекторів.
* AJAX-черга обходу сторінок та збереження профілів селекторів.
* CSV-експорт із налаштовуваним роздільником.
* Базова публікація записів/сторінок WordPress і простих товарів WooCommerce.
* Перевірка дублікатів за URL джерела.
* Оновлення через GitHub Releases.

== Встановлення ==
1. Завантажте ZIP-архів релізу.
2. У WordPress відкрийте Плагіни → Додати новий → Завантажити плагін.
3. Активуйте UA Parser.
4. Для публікації товарів потрібен активний WooCommerce.

== Важливо ==
Повна реалізація ТЗ ще триває. Beta.8 додає редагування назви, опису, ціни, URL фото, атрибутів і варіацій; порядок фото можна змінити у списку URL. Додано базове виявлення sitemap і обходу пагінації. Нестандартні JS-конфігуратори, повне редагування категорій/міток, перевірка всіх форматів сторонніх імпортерів та реальні тести на різних сайтах ще потребують роботи. Не використовуйте цей beta-реліз для масового перенесення без попередньої перевірки на тестовому сайті.

== Оплата та ліцензування ==
Плагін не містить платіжних інтеграцій, Freemius, ліцензійних перевірок, тарифів або платних обмежень.

== Безпека ==
Збір виконується сервером WordPress. Адміністративні дії обмежені правом manage_options. Перевіряйте права на контент і правила сайтів-джерел. Перед масовим імпортом використовуйте staging-середовище.
