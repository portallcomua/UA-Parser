Універсальний збирач публічних вебсторінок для підготовки даних до WordPress та WooCommerce.

== Поточний стан beta.6 ==
* Базове отримання HTML публічних HTTP/HTTPS сторінок.
* Базове витягування заголовка, опису, ціни та URL зображень.
* Попередній перегляд сторінки в ізольованому iframe та основа візуального вибору CSS-селекторів.
* AJAX-черга обходу сторінок та збереження профілів селекторів.
* CSV-експорт із налаштовуваним роздільником.
* Базова публікація записів/сторінок WordPress і простих товарів WooCommerce.
* Перевірка дублікатів за URL джерела.
* Оновлення через GitHub Releases.

== Встановлення ==
1. Завантажте ZIP-архів релізу.
2. У WordPress відкрийте Плагіни → Додати новий → Завантажити плагін.
3. Активуйте UA Parser.
4. Для публікації товарів потрібен активний WooCommerce.

== Важливо ==
Повна реалізація ТЗ ще триває. Наразі не завершені повноцінне редагування результатів, керування галереєю, множинні значення атрибутів і генерація варіацій WooCommerce, а також перевірені профілі імпорту сторонніх CMS. Не використовуйте цей beta-реліз для масового перенесення без попередньої перевірки на тестовому сайті.

== Оплата та ліцензування ==
Плагін не містить платіжних інтеграцій, Freemius, ліцензійних перевірок, тарифів або платних обмежень.

== Безпека ==
Збір виконується сервером WordPress. Адміністративні дії обмежені правом manage_options. Перевіряйте права на контент і правила сайтів-джерел. Перед масовим імпортом використовуйте staging-середовище.
