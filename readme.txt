Збір даних з однієї публічної сторінки та базова публікація у WordPress/WooCommerce.

== Можливості alpha.1 ==
* Аналіз однієї публічної HTTP/HTTPS сторінки.
* Витягування заголовка, опису, кандидата ціни та URL зображень.
* Тимчасове збереження зібраного набору для поточного адміністратора.
* Експорт CSV із роздільником крапка з комою.
* Публікація як запису або сторінки WordPress.
* Публікація простого товару WooCommerce, якщо WooCommerce активний.
* Завантаження першого знайденого зображення у медіатеку як мініатюри.
* Пропуск повторної публікації за URL джерела.
* Адаптивна адмін-сторінка українською.

== Встановлення ==
1. Відкрийте гілку ua-parser-5.0-dev у GitHub.
2. Натисніть Code → Download ZIP.
3. У WordPress відкрийте Плагіни → Додати новий → Завантажити плагін.
4. Завантажте ZIP, встановіть та активуйте UA Parser.
5. Відкрийте пункт меню UA Parser.
6. Спочатку тестуйте на тестовому сайті та зберігайте результати як чернетки.

== Обмеження alpha.1 ==
Це рання робоча основа, а не завершений реліз. Обробляється одна введена сторінка за запит. Візуальний вибір елементів, автоматичне визначення повторюваних карток, пакетний обхід категорій/пагінації/sitemap, профілі експорту для інших CMS, повна галерея товару, SKU, категорії, атрибути, англійська локалізація, Freemius та GitHub updater ще не реалізовані.

Перед використанням на робочому сайті зробіть резервну копію. Перевіряйте права на використання текстів і зображень джерела. Не використовуйте плагін для обходу авторизації, CAPTCHA або технічних обмежень сайтів.
