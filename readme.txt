Збір контенту з публічних вебсторінок та перенесення матеріалів у WordPress.

== Можливості beta.1 ==
* Аналіз однієї сторінки: заголовок, опис, ціна, зображення.
* Обмежений обхід до 20 внутрішніх посилань із початкової сторінки.
* Перегляд результатів та вибір позицій для публікації.
* Публікація як запис, сторінка або простий товар WooCommerce.
* Завантаження першого зображення як головного зображення.
* Пропуск дублікатів за URL джерела.
* Експорт CSV з роздільником крапка з комою.
* Адаптивний інтерфейс.

== Встановлення ==
1. Завантажте ZIP гілки ua-parser-5.0-rebuild.
2. У WordPress відкрийте Плагіни → Додати новий → Завантажити плагін.
3. Активуйте UA Parser.
4. Для публікації товарів потрібен активний WooCommerce.

== Важливо ==
Це проміжна beta-збірка, а не завершення повного технічного завдання. В ній ще немає візуального CSS-селектора, багаторівневого crawler із пагінацією/sitemap, фонової черги, редактора полів, галерей/атрибутів/SKU, CMS-профілів експорту, Freemius та GitHub updater. Не використовуйте для масового збору без перевірки прав на контент і навантаження на джерело.

== Безпека ==
Збір виконується сервером WordPress. Доступ до адміністративних дій обмежений користувачами з manage_options. Тестуйте в staging-середовищі перед використанням на робочому сайті.
