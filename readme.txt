Універсальний збір контенту з публічних сторінок із візуальним вибором полів, пакетним обходом сторінок та перенесенням даних у WordPress/WooCommerce.

== Реалізовано у beta.2 ==
* Візуальний попередній перегляд HTML у ізольованому iframe.
* Вибір елемента натисканням/дотиком; визначення CSS-селектора та перегляд знайдених значень.
* Типи полів: назва, опис, ціна, зображення, бренд, SKU, колір та додатковий атрибут.
* Збереження профілів вибору полів для повторного використання.
* Пакетна AJAX-черга з окремими кроками, лічильниками, збереженням стану у transient та відновленням під час активної сесії адміністратора.
* Пошук rel=next та посилань пагінації; обмеження до 500 сторінок за один запуск.
* Виявлення до 30 зображень на сторінці, завантаження головного зображення та галереї WooCommerce.
* Вилучення мікророзмітки brand, SKU, color, size, GTIN та category.
* Створення видимих атрибутів товару WooCommerce, SKU та категорій, якщо їх знайдено.
* Вибір окремих результатів для публікації як запис, сторінка або товар; чернетка чи публікація.
* Пропуск дублікатів за URL джерела.
* CSV-профілі колонок для Prom, Rozetka, OpenCart, VirtueMart, JoomShopping, WooCommerce та WordPress.
* Адаптивний інтерфейс для телефону та комп’ютера.

== Встановлення ==
1. Завантажте ZIP гілки ua-parser-5.0-rebuild.
2. У WordPress відкрийте Плагіни → Додати новий → Завантажити плагін.
3. Активуйте UA Parser.
4. Для публікації товарів потрібен активний WooCommerce.

== Freemius ==
Інтеграційний bootstrap передбачений, але SDK і реальні ідентифікатори продукту не додаються автоматично. Для активації потрібно додати офіційний Freemius SDK у каталог freemius/ та визначити у wp-config.php:
* UAP50_FREEMIUS_ID
* UAP50_FREEMIUS_PUBLIC_KEY

Без SDK та справжніх ID/ключа Freemius не активується. Не підставляйте тестові або вигадані значення.

== Обмеження beta.2 ==
* Профілі CMS є стартовими CSV-мапінгами колонок, а не сертифікованими шаблонами імпорту кожного маркетплейсу. Перед масовим імпортом звірте формат із поточним шаблоном цільової CMS.
* Черга працює пакетами через AJAX, поки сторінка адміністратора відкрита; це не окремий системний cron-worker.
* Селектор підтримує прості CSS-селектори за тегом, ID та класами. Складні псевдокласи, комбіновані групи та JavaScript-rendered сторінки не підтримуються.
* Для сайтів, що генерують контент лише через JavaScript, потрібен окремий headless-browser механізм.
* GitHub Releases updater підключений; для оновлення потрібен опублікований реліз із ZIP-asset `ua-parser.zip`.

== Безпека ==
Збір виконується сервером WordPress. Доступ до адміністративних дій обмежений користувачами з manage_options. Приватні/локальні IP-адреси блокуються, автоматичні HTTP-перенаправлення вимкнені. Використовуйте staging-середовище, дотримуйтесь правил джерела та перевіряйте права на контент.
